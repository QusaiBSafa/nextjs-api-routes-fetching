# nextjs-api-routes-fetching

## Description
A Next.js application that demonstrates how to use API routes for data fetching from an external API.

## What's Built
- Two API endpoints that fetch data from a public API.
- A simple frontend that displays the fetched data.

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/nextjs-api-routes-fetching.git
   cd nextjs-api-routes-fetching
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:3000`.

## API Documentation
### GET /api/users
Fetches a list of users from an external API.

### GET /api/posts
Fetches a list of posts from an external API.

## Environment Variables
No environment variables are required for this application.
